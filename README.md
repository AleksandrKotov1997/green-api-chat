# GREEN-API Chat

Тестовое задание на позицию Frontend React Developer.

Приложение позволяет создавать чат по номеру телефона, отправлять и получать текстовые сообщения через GREEN-API.

В задании основным мессенджером указан MAX, при этом разрешено использовать Telegram или WhatsApp, если интеграция с MAX недоступна. В проекте используется Telegram через GREEN-API, а внешний вид интерфейса выполнен с ориентацией на web-версию MAX.

## Возможности

- ввод `idInstance` и `apiTokenInstance`;
- ввод номера получателя;
- проверка существования аккаунта получателя;
- создание чата;
- отправка текстовых сообщений;
- получение входящих текстовых сообщений;
- обработка очереди уведомлений GREEN-API;
- игнорирование нетекстовых сообщений;
- отображение ошибок API;
- отправка сообщения по `Enter`;
- перенос строки по `Shift + Enter`.

Приложение работает только с текстовыми сообщениями, как требуется в задании.

## Архитектура

Проект состоит из frontend-приложения и небольшого BFF-слоя на Vercel Functions.

```text
api/
  check-account.ts
  delete-notification.ts
  receive-notification.ts
  send-message.ts

server/
  greenApi/
  http/

src/
  api/
  shared/
  views/
```

Frontend обращается к `/api/*`, после чего Vercel Functions выполняют запросы к GREEN-API.

Такой подход позволяет избежать прямых запросов из браузера к GREEN-API и связанных с ними CORS-ограничений.

Для получения сообщений используется HTTP API GREEN-API:

```text
ReceiveNotification
        ↓
обработка уведомления
        ↓
DeleteNotification
```

Нетекстовые уведомления не отображаются в интерфейсе, но удаляются из очереди, чтобы не блокировать получение следующих сообщений.

## Локальный запуск

Для запуска необходимы:

- Node.js;
- pnpm.

Vercel CLI установлен в проект как dev dependency и будет доступен после `pnpm install`.

### 1. Установить зависимости

```bash
pnpm install
```

### 2. Авторизоваться в Vercel

Если Vercel CLI ещё не авторизован:

```bash
pnpm exec vercel login
```

### 3. Запустить приложение

Для полноценного локального запуска frontend и Vercel Functions используется:

```bash
pnpm dev:vercel
```

Команда запускает локальное Vercel-окружение, включая frontend и маршруты `/api/*`.

После запуска приложение будет доступно по адресу, который выведет Vercel CLI, обычно:

```text
http://localhost:3000
```

При первом запуске Vercel CLI может предложить настроить или связать локальный проект.

Команда:

```bash
pnpm dev
```

запускает только Vite frontend и не поднимает локальные Vercel Functions. Для проверки полного функционала приложения используйте `pnpm dev:vercel`.

## Настройка GREEN-API

Для работы приложения необходим активный экземпляр GREEN-API для Telegram.

После создания экземпляра необходимо:

1. Авторизовать Telegram в GREEN-API.
2. Включить получение уведомлений о входящих сообщениях.
3. Скопировать:
   - `idInstance`;
   - `apiTokenInstance`.

Эти данные вводятся непосредственно в интерфейсе приложения.

Credentials не сохраняются в `localStorage` или других постоянных хранилищах приложения.

## Использование

1. Ввести `ID Instance`.
2. Ввести `API Token Instance`.
3. Указать номер получателя в международном формате только цифрами.
4. Нажать `Create chat`.
5. Ввести сообщение.
6. Отправить его кнопкой `Send` или клавишей `Enter`.

Полученные от собеседника текстовые сообщения автоматически появляются в чате.

`Shift + Enter` используется для переноса строки.

## Ограничения

В соответствии с тестовым заданием приложение имеет минимальный набор функций:

- один активный чат;
- только текстовые сообщения;
- без хранения истории сообщений;
- без отправки файлов;
- без списка контактов и дополнительных функций мессенджера.

После перезагрузки страницы текущая сессия чата очищается.
